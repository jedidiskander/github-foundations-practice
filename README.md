## Basic Git Commands

- `git clone` — copies a repository to your computer
- `git status` — shows the current state of your files
- `git add` — stages changes
- `git commit` — saves a snapshot of staged changes
- `git push` — uploads commits to GitHub
- `git pull` — downloads and integrates remote changes
